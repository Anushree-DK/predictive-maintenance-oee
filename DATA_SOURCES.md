# Data Sources

## NASA Turbofan Engine Degradation Simulation Data Set (C-MAPSS)

- **Source**: NASA Prognostics Center of Excellence (PCoE) Data Set Repository —
  https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/
- **Citation**: A. Saxena and K. Goebel (2008). "Turbofan Engine Degradation
  Simulation Data Set", NASA Prognostics Data Repository, NASA Ames Research
  Center, Moffett Field, CA.
- **License/terms**: The repository page states no formal license (no CC-BY,
  no public-domain declaration); it carries a liability disclaimer ("Users
  employ the data at their own risk...") and requests that publications using
  the data "acknowledge both the assistance received by using this repository
  and the donators of the data" — a request, not a stated legal requirement.
  No commercial-use or redistribution restriction is stated.
- **Used for**: sensor telemetry (21 sensors, 3 operational settings, run-to-
  failure and partial trajectories), loaded via `scripts/load_cmapss.py` from
  the FD001 subset (`train_FD001.txt`, `test_FD001.txt`, `RUL_FD001.txt`).
  This is real NASA data, not synthetic — see below for what isn't.

## Synthetic data (generated by this project)

C-MAPSS has no equivalent of machine names, maintenance records, or
production/OEE data, since it's a pure sensor-simulation dataset. These are
generated locally to complete the enterprise scenario:

- **`MACHINE_DATA`** — machine names, production lines, models, install
  dates. Generated in `scripts/generate_mock_data.py::generate_machine_data`.
- **`MAINTENANCE_HISTORY`** — preventive/inspection/corrective event records.
  Generated in `scripts/generate_mock_data.py::generate_maintenance_history`.
- **`PRODUCTION_DATA`** — shift-level planned time, downtime, cycle counts
  used for the OEE calculation. Generated in
  `scripts/generate_mock_data.py::generate_production_data`.
- **`ACTION_OUTCOMES`** — starts empty; populated only by real interaction
  with the dashboard's agentic action buttons, not pre-generated.

None of this synthetic data represents any real company, machine, or
production line — it exists only to make the sensor data usable in a
realistic enterprise data model.
